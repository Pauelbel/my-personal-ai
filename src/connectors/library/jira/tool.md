Коннектор к Jira только на чтение. Код — script.py рядом: его можно поправить в окне «файлы» или попросить агента доработать (propose с name jira). Шаблоны запросов — в подсказке ниже: допишите свои проекты, компоненты и частые запросы.
Доступы задаются формой «настроить» (Возможности → Инструменты → Коннекторы): JIRA_URL и JIRA_TOKEN обязательны; JIRA_EMAIL — только для Jira Cloud; JIRA_VERIFY_SSL=false — для корпоративного сертификата. Знак ? после имени — секрет необязательный.

## Параметры
- jql — запрос JQL, например key = QA-123
- limit — сколько задач вернуть, по умолчанию 20, не больше 50 (число) (необязательно)

## Подсказка модели
Шаблоны JQL:
- задача по ключу: key = QA-123
- мои незакрытые задачи: assignee = currentUser() AND resolution = Unresolved ORDER BY updated DESC
- поиск по тексту: text ~ "фильтр отчёта" ORDER BY updated DESC
- баги компонента: issuetype = Bug AND component = "Название" AND resolution = Unresolved
Ключ задачи пиши заглавными буквами (QA-123). Если Jira ответила ошибкой в JQL — исправь запрос по тексту ошибки и вызови снова.
