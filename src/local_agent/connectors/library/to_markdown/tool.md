Переводит документы в Markdown пакетом markitdown (Microsoft) в окружении песочницы. Пакет ставится один раз: если его нет, агент предложит установку карточкой install_packages.
Результат — рядом с документом: docs/spec.pdf → docs/spec.md, или по пути save. Чужой файл .md с таким именем не перезаписывается — результат тогда ляжет в docs/spec.pdf.md. Папка обрабатывается со всеми вложенными папками; документы, у которых перевод новее самого документа, пропускаются — так повторный запуск переводит только новое и доделывает то, что не успело за таймаут.
Скан без текстового слоя (картинки страниц) так не перевести: для него нужен OCR.
Код — script.py рядом: его можно поправить в окне папки или попросить агента доработать (propose с name to_markdown).
