## Нужно от вас
- задача — ключ задачи, например QA-123

## Прочитать задачу
инструмент: jira
параметры: {"action": "issue", "key": "{задача}"}
сохранить: .meepo/jira/{задача}.md

## Разобрать требования
модель: Ты — QA-аналитик. Разбери задачу:
1. Коротко: что меняется и для кого.
2. Вопросы к требованиям: неясное, противоречия, пропущенные случаи — по пунктам, чтобы их можно было задать аналитику.
3. Риски: что может сломаться рядом (регресс), зависимости, данные.
4. Чек-лист проверки: позитивные, негативные и граничные проверки, по строке на проверку.
Опирайся только на текст задачи и комментарии.
файлы: .meepo/jira/{задача}.md
сохранить: reports/{задача}-review.md
