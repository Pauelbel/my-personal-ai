Агент проходит сценарий в настоящем браузере и сверяет каждый шаг с ожидаемым по свежему снимку страницы. Протокол — в reports/browser-check.md, баг-репорты на провалы — в reports/bugs.md.

Не проходи сценарий сам — запусти шаги через run_skill (inputs: сайт, сценарий, доступы).
