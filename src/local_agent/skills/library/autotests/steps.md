## Нужно от вас
- сайт — адрес сайта, например https://www.saucedemo.com
- шаблон — ссылка на git-репозиторий с шаблоном автотестов
- сценарии — что покрыть тестами: по строке на сценарий
- доступы — логины и пароли для входа (необязательно)

## Скачать шаблон
команда: git clone --depth 1 {шаблон} .meepo/template || git -C .meepo/template pull --ff-only
таймаут: 180

## Выписать правила шаблона
модель: Перед тобой шаблон проекта UI-автотестов. Выпиши правила, по которым в нём пишутся тесты, — так, чтобы новый тест нельзя было отличить от существующих:
1. Структура папок: где тесты, страницы (page objects), фикстуры, тестовые данные, конфиги.
2. Как устроен тест: фикстуры, подготовка, проверки (assert или expect), маркеры, параметризация.
3. Как описываются страницы и локаторы; базовые классы и хелперы — с путями к файлам и сигнатурами.
4. Названия файлов, классов и функций; язык комментариев и докстрингов; отчёты (Allure и т. п.).
5. Как запускать тесты и какие нужны зависимости.
В конце приведи один короткий тест целиком в стиле шаблона. Пиши только то, что видно в файлах.
файлы: .meepo/template
сохранить: .meepo/autotests/rules.md

## Найти элементы на сайте
агент: Открой {сайт} в браузере и пройди каждый сценарий по-настоящему, шаг за шагом.
Сценарии:
{сценарии}
Доступы: {доступы}
Для каждого сценария запиши: шаги, адреса страниц, и для каждого элемента, с которым действовал или который проверял, — надёжный локатор (data-test, id, роль с именем, текст) и что на странице должно быть после шага (точный текст со страницы). Записывай только то, что видел в снимке страницы.
инструменты: браузер
шагов: 60
сохранить: .meepo/autotests/locators.md

## Написать тесты
агент: Напиши автотесты для сценариев по правилам шаблона и с элементами со страницы (оба файла выше). Раскладывай файлы в папке проекта так же, как они лежат в шаблоне (.meepo/template можно читать): страницы, фикстуры, тесты, конфиги, зависимости. Файлы в .meepo не меняй. Каждый сценарий — отдельный тест. В конце перечисли созданные файлы.
файлы: .meepo/autotests/rules.md, .meepo/autotests/locators.md
инструменты: файлы
шагов: 40

команда:
```bash
PY=python3; [ -x .venv/bin/python ] && PY=.venv/bin/python
$PY -m pytest -q
```
