---
name: Автотесты
description: написать автотесты для функции, модуля или API в стиле существующих тестов проекта; использовать по просьбе «напиши тесты», «покрой тестами», «добавь автотест»
---
Цель: тесты, которые соответствуют принятым в проекте подходам и проверяют поведение, а не реализацию.

1. Определи стек тестов: прочитай через read_file pyproject.toml, package.json или аналог. Найди папку тестов через list_files.
2. Прочитай один-два существующих теста на похожий код и общие фикстуры (conftest.py, setup-файлы). Повторяй их стиль: именование, фикстуры, моки, структуру.
3. Прочитай тестируемый код через read_file. Выпиши сценарии: основной путь, границы, ошибки и исключения, пустые значения. Покажи список пользователю одной строкой на сценарий.
4. Напиши тесты:
   - один тест — одно поведение; имя описывает поведение: `test_empty_phone_returns_error`;
   - схема «подготовка — действие — проверка»;
   - мокай только внешнее: сеть, время, файловую систему вне временной папки;
   - не проверяй приватные детали, которые изменятся при рефакторинге.
5. Новый файл создай через write_file, в существующий добавь через edit_file. Запись выполняется после подтверждения пользователя.

Ты не можешь запускать тесты. В конце назови команду запуска из README или конфигурации и попроси пользователя прислать результат, если тест упадёт. Не утверждай, что тесты проходят.
