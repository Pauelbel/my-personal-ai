---
name: Тест-кейсы
description: составить чек-лист и тест-кейсы по требованию, задаче или фиче; использовать по просьбе «напиши тест-кейсы», «как это протестировать», «чек-лист проверки»
---
Цель: набор проверок, по которому человек может протестировать фичу, не додумывая шаги.

Если нужно покрыть тест-кейсами раздел или страницу документации целиком, вызови generate_test_cases с путём раздела. За вызов обрабатывается limit страниц (по умолчанию 3); перескажи итог из результата и предложи продолжить тем же вызовом, если страницы остались. Шаги ниже — для одной фичи или требования.

1. Найди источник требований. Если пользователь прислал текст — работай по нему. Иначе ищи требования в документации через search_docs: сделай 2–3 запроса разными словами (название фичи, поля, экраны, ошибки). Найденный раздел при необходимости дочитай через read_file по пути и строке из результата.
   Если документации нет или в ней не хватает деталей, найди код через search_files и прочитай его через read_file: ищи условия, ограничения, сообщения об ошибках, значения по умолчанию.
2. Если требования неясны (нет лимитов, непонятно поведение при ошибке), выпиши вопросы отдельным списком. Не выдумывай ожидаемый результат: пометь такой кейс «уточнить».
3. Подбери проверки по техникам:
   - **Позитивные** — основной сценарий и его варианты.
   - **Классы эквивалентности и границы** — для каждого поля или параметра: минимум, максимум, на единицу за границей, пусто.
   - **Негативные** — неверный формат, отсутствие прав, недоступный внешний сервис, повторное действие.
   - **Состояния и переходы** — если у объекта есть статусы.
4. Убери дубли: из одного класса эквивалентности бери одно значение.

Формат ответа:
- Источники: файлы документации, по которым составлены кейсы.
- Вопросы к требованиям (если есть).
- Чек-лист: одна строка — одна проверка, с приоритетом P1/P2/P3.
- Тест-кейсы для P1 таблицей: ID | Название | Предусловия | Шаги | Ожидаемый результат.

Если пользователь просит сохранить кейсы в файл, запиши их через write_file в указанный путь.
