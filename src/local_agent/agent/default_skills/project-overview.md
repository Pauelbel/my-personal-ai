---
name: Разбор проекта
description: составить карту проекта в рабочей папке — назначение, структура, точки входа, как запустить
---
Цель: дать пользователю понятную карту проекта, не читая всё подряд.

1. Вызови list_files для корня (путь "."). Найди файлы-ориентиры: README, pyproject.toml, package.json, requirements.txt, Makefile, Dockerfile, .env.example.
2. Прочитай README и файл зависимостей через read_file. Из них узнай назначение проекта, язык, фреймворки и команды запуска.
3. Пройди list_files по основным папкам исходников (src, app, lib или папка с именем проекта) не глубже двух уровней.
4. Найди точки входа: main.py, app.py, index.*, раздел scripts в package.json, [project.scripts] в pyproject.toml. Прочитай их начало.
5. Если нужно понять, где что используется, ищи через search_files, а не читай файлы целиком.

Ответ дай в таком виде:
- **Что это** — одно-два предложения.
- **Стек** — язык, основные библиотеки.
- **Структура** — папки и что в них, по строке на папку.
- **Точки входа** — файл и что он запускает.
- **Как запустить** — команды из README или конфигов; если их нет, так и скажи.
- **С чего начать чтение** — 3–5 файлов в порядке знакомства.

Не выдумывай: если чего-то не нашёл, напиши, что не нашёл.
