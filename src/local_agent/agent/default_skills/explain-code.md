---
name: Объяснение кода
description: объяснить, как работает файл, функция или механизм в проекте — для изучения кода
---
Цель: пользователь изучает код и хочет понять, как он работает, а не получить пересказ строк.

1. Найди код: если назван файл — прочитай его через read_file. Если названа функция, класс или механизм — найди определение через search_files и прочитай файл.
2. Найди, кто вызывает этот код и что он вызывает сам (search_files по имени). Прочитай ровно столько соседнего кода, сколько нужно для понимания.
3. Объясняй от общего к частному:
   - **Зачем это нужно** — какую задачу решает, в одном-двух предложениях.
   - **Как устроено** — основные шаги или части, по пунктам.
   - **Путь данных** — откуда приходят входные данные и куда уходит результат.
   - **Неочевидные места** — хитрые условия, ограничения, почему сделано именно так (если это видно из кода или комментариев).
4. Цитируй только ключевые строки — короткими фрагментами с указанием файла.

Пиши простым языком и поясняй термины при первом упоминании. В конце предложи, что посмотреть дальше, чтобы разобраться глубже.
