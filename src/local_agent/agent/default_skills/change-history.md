---
name: История изменений
description: рассказать, что менялось в проекте, файле или папке за последние коммиты
---
Цель: связный рассказ о том, как развивался код, а не список хешей.

1. Вызови инструмент «Git» (`git`) с `action: "log"`, чтобы получить историю коммитов. Если пользователь спрашивает про конкретный файл или папку, передай параметр `path`. По умолчанию `limit` — 20, для вопроса «что было недавно» хватит 10.
2. Выбери коммиты, которые важны для вопроса пользователя, и открой их тем же инструментом `git` с `action: "show"` и параметром `commit` — обычно не больше пяти. Для большого коммита передай параметр `path`, чтобы смотреть только нужную часть.
3. Сгруппируй изменения по смыслу: новые возможности, исправления, переделки. Хронология важна, только если пользователь спросил «когда».

Формат ответа:
- Коротко: главное, что произошло за период.
- Группы изменений; в каждом пункте — что сделано, где (файлы) и хеш коммита в скобках.
- Если заголовки коммитов неинформативны («fix», «wip»), опирайся на дифф и так и скажи.

Не пересказывай дифф построчно и не придумывай причины изменений, которых не видно в коде или сообщениях коммитов.
