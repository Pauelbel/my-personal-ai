# Meepo — самодостраивающийся локальный агент

<img src="src/local_agent/ui/assets/meepo-logo.png" alt="Три Мипо — логотип проекта" width="440">

Локальный агент с веб-интерфейсом на локальной модели (LM Studio, Ollama или другой OpenAI-compatible сервер; по умолчанию `google/gemma-4-12b`, окно ~8k токенов). На старте есть только основной агент. Он общается с вами, запоминает вас и по ходу работы наращивает возможности: инструменты, скиллы и саб-агентов. Каждое добавление — только после обсуждения и вашего явного утверждения.

![Meepo: чат по центру, справа карточка предложенного инструмента с кодом](docs/images/app-screenshot.png)

## Как агент растёт

| Уровень | Что это | Где лежит |
| --- | --- | --- |
| Инструменты | Встроенные (файлы, git, поиск по документации, чтение ссылок, вики), MCP (веб-поиск, браузер) и Python-скрипты, которые пишет сам агент | `data/tools/<id>/` — `tool.md`, `parameters.json`, `script.py` |
| Скиллы | Инструкции под тип задач | `data/skills/<id>.md` |
| Саб-агенты | Помощники с постоянной ролью, своими инструментами и скиллами | `data/agents/<id>.md` |

- Когда возможности не хватает, агент прямо говорит об этом и предлагает её создать (`propose`). Справа появляется карточка с предложением целиком: что, зачем, код или текст. Её можно **утвердить**, **отклонить** или **ответить** текстом. Ответить можно и обычным сообщением в чате, тогда агент доработает предложение.
- Ненужное агент предлагает убрать в архив (`archive`), и оттуда же можно вернуть. Готовые дополнения тоже лежат в архиве, например генерация тест-кейсов по документации (`generate_test_cases`): агент видит их и может предложить подключить.
- Всё созданное — обычные файлы. Их можно поправить руками и нажать «Перечитать с диска» в разделе «Возможности».
- **Команда** — холст сессии: основной агент, его саб-агенты и стрелки «кому поручал», у каждого статус (работает, ждёт решения, выполнил задачу) и текущая задача. Щелчок по агенту — разговор с ним; та же полоса переключения агентов есть над чатом. Написать саб-агенту можно и напрямую: его ответы вам в основной чат не уходят.
- Саб-агенту основной агент поручает задачу через `delegate`. Задача идёт в фоне, в дочерней сессии, а разговор с вами продолжается. Статус виден в блоке «саб-агенты» над полем ввода, результат приходит в чат отдельным сообщением (длинный — свёрнутым). Подтверждения саб-агента приходят карточками в панель «Требует внимания» справа.
- **Связи на холсте «Команда»**: потяните от точки на краю карточки одного саб-агента к другому — первый сможет спросить второго посреди своей задачи (`ask_agent`) и дождётся ответа. Связь хранится в файле агента строкой `agents:`; щелчок по линии её убирает.

## Маленький контекст

- В системный промпт попадает **компактный реестр**: имя и одна строка описания у каждого инструмента, скилла и саб-агента. Схемы параметров подключаются, только когда агент выбрал инструмент (`activate`), и одновременно подключено не больше 5. Подключённые запоминаются на проект; чтение файлов (`list_files`, `read_file`) подключено сразу.
- **Память** о вас не вставляется целиком. В промпт попадают короткий профиль (`profile.md`) и несколько записей, найденных полнотекстовым поиском по сообщению. Факты агент записывает сразу (`remember`), через patch-контракт из [docs/memory-contract.md](docs/memory-contract.md), а раз в несколько сообщений разбирает разговор целиком.
- **Вики** — отдельная папка и отдельный индекс. Пришлите ссылку или статью, агент сделает заметку в Markdown, и её можно найти. Саб-агенты видят вики, но не вашу память.
- Ранняя часть разговора сворачивается в короткое резюме, а старые результаты инструментов обрезаются.

## Архитектура

- **Ход агента** — граф LangGraph (`src/local_agent/graph/agent_graph.py`): `call_model → approve → run_tools → call_model …`. Все подтверждения проходят через `interrupt` в узле `approve`, в котором нет побочных эффектов. Ход, который ждёт решения, хранится в SQLite-чекпоинте (`data/checkpoints.sqlite`) и в сессии, поэтому переживает перезагрузку страницы и сервера.
- **Модель** вызывается своим провайдером (`llm/openai_compatible.py`) прямо из узлов графа: он передаёт рассуждения (`reasoning_content`) в UI, сам собирает вызовы инструментов из стрима и узнаёт размер окна у сервера. Если модель ответила пустотой, запрос повторяется, последний раз без инструментов.
- **Реестр** инструментов единый: встроенные, созданные агентом и MCP регистрируются одинаково (`tools/registry.py`, `capabilities/`).
- **Скрипты агента** выполняются в песочнице (`capabilities/sandbox.py`): bubblewrap (файловая система только для чтения, домашняя папка скрыта, сеть закрыта, если инструмент не заявил её), таймаут, лимиты памяти и вывода, чистое окружение. В рабочую папку может писать только инструмент, каждый вызов которого вы подтверждаете.
- **MCP**: серверы описаны в `data/mcp.json` (создаётся при первом запуске): веб-поиск DuckDuckGo (`uvx duckduckgo-mcp-server`) и браузер Playwright (`npx @playwright/mcp`, нужен Node.js). Без подтверждения выполняются только инструменты из `auto_approve` или с пометкой «только чтение».
- **Ход идёт на сервере**, а не во вкладке (`agent/turn_hub.py`): закрытая или перезагруженная вкладка подключается к нему заново, «Стоп» (■ или Esc) — отдельная команда. Сообщение, отправленное во время хода, встаёт в очередь и уходит после ответа; после остановки, ошибки или карточки очередь ждёт вас. Об изменениях интерфейс узнаёт из потока `/api/events`, а не опросом.
- **Бэкенд** — FastAPI, **UI** — чистый JS без сборки: слева проекты и сессии (со статусами «работает», «ждёт», «новое»), чат по центру, справа карточки решений — только когда они есть; разделы «Команда», «Файлы», «Вики», «Возможности», «Память». Под ответом — время хода, токены и скорость, у поля ввода — модель, права проекта и заполненность контекста. После сбоя хода есть «Повторить» — без второй копии сообщения.

## Настройка и запуск

Нужны Python 3.11+, [`uv`](https://docs.astral.sh/uv/) и LM Studio (или Ollama) с загруженной моделью и включённым API-сервером. Для изоляции скриптов агента нужен `bwrap` (пакет `bubblewrap`), для браузерного MCP — Node.js.

```bash
cp .env.example .env        # проверьте LLM_BASE_URL и DEFAULT_MODEL
uv sync
uv run uvicorn local_agent.main:app --host 127.0.0.1
```

Откройте [127.0.0.1:8000](http://127.0.0.1:8000/). Аутентификации нет: запускайте только на `127.0.0.1`.

- **Ollama вместо LM Studio:** `LLM_BASE_URL=http://127.0.0.1:11434/v1`, `DEFAULT_MODEL=gemma4:12b`.
- **Проект** — рабочая папка, в которой работают файловые и git-инструменты. Проекты и их сессии — в панели слева: «＋ проект» создаёт новый, ✎ у проекта или его имя в шапке открывают настройки. Сессии без проекта попадают в проект черновиков (папка `data/drafts`, по умолчанию так и называется — `drafts`). У проекта есть режим «только чтение»: инструменты, меняющие файлы или систему, агенту в нём недоступны.
- **Саб-агенты на отдельной модели:** задайте `SUBAGENT_PROVIDER` и `SUBAGENT_MODEL`, чтобы фоновые задачи не ждали основную модель.

## Данные

| Путь | Что хранит |
| --- | --- |
| `data/sessions`, `data/conversations` | Сессии (JSON) и история (JSONL); дочерние сессии саб-агентов скрыты из списка |
| `data/projects` | Проекты: рабочая папка, провайдер и модель |
| `data/memory` | Долговременная память о вас (Markdown) |
| `data/wiki` | Заметки вики (Markdown) |
| `data/tools`, `data/skills`, `data/agents` | Созданные возможности; архив — в `.deleted` |
| `data/index` | Полнотекстовые индексы памяти, вики и документации проектов |
| `data/checkpoints.sqlite` | Ходы, которые ждут решения |
| `data/mcp.json`, `data/logs` | MCP-серверы и их журналы |

Все настройки и пути — в [.env.example](.env.example).

## Проверка

```bash
uv sync --all-extras
uv run ruff check src tests
uv run pytest
# на живой модели (LM Studio или Ollama):
LM_STUDIO_TEST_MODEL=gemma4:12b LLM_BASE_URL=http://127.0.0.1:11434/v1 uv run pytest tests/test_live_lm_studio.py
# spike: tool calling, structured output, interrupt/resume на модели
uv run --extra spike python spikes/gemma_langgraph.py --ollama
```

## Генерация тест-кейсов из командной строки

Конвейер из `extras/testgen` можно запустить и без агента:

```bash
uv run python -m local_agent.extras.testgen "docs/раздел" --workspace ~/project --limit 10
```
