# Мипо

Личный локальный ассистент QA-инженера. Вы даёте задачу текстом — Мипо выполняет её сам в папке проекта:
читает и пишет файлы, запускает скиллы, команды и браузер. Для задачи нет инструмента — Мипо предлагает новый
скилл (описание, код, библиотеки) и после вашего «да» создаёт его. Всё, что меняет файлы, систему или браузер,
идёт через карточку подтверждения.

Модель только локальная: LM Studio или Ollama (OpenAI-совместимый API), до 14B. Рабочие данные в облако не уходят.

## Установка

Нужны Python 3.11+ и [uv](https://docs.astral.sh/uv/).

**Linux**

```bash
git clone <репозиторий> my-personal-ai && cd my-personal-ai
uv sync
uv run playwright install chromium      # один раз: браузер для инструмента browser
cp .env.example .env                    # адрес сервера модели и модель
```

**Windows (PowerShell)**

```powershell
git clone <репозиторий> my-personal-ai; cd my-personal-ai
uv sync
uv run playwright install chromium
Copy-Item .env.example .env
```

Если Chromium не скачан, браузер попробует установленный Google Chrome.

## Модель

В разделе «Настройки» добавьте локальный LLaMA-сервер (llama.cpp, LM Studio или Ollama) либо внешний
OpenAI-совместимый API. Укажите адрес, выберите полученную с сервера модель, а для внешнего API при необходимости
добавьте ключ. Подключение можно полностью сбросить. Пока оно не настроено, выбор модели над чатом скрыт.

Переменные `LLM_BASE_URL`, `LLM_API_KEY` и `DEFAULT_MODEL` в `.env` остаются резервным способом настройки.

## Запуск

```bash
uv run python -m meepo.main
```

Откройте http://127.0.0.1:8000, нажмите «Выбрать папку проекта» и напишите задачу.

## Разделы

- **Чат** — проекты и сессии слева; ход работы свёрнут в одну строку над ответом, решения — карточками над полем ввода,
  «Стоп» — кнопкой или Esc. Над полем ввода — сколько окна модели занято.
- **Вики** — заметки, граф, чат вики со своим агентом («добавь заметку», «проверь вики»).
- **Скиллы** — SKILL.md, код, библиотеки, секреты (значения вводятся здесь и не уходят в модель), история с откатом.
- **Память** — факты о вас: `profile.md`, `preferences.md`, `projects.md`, `solutions.md`; обновляется сама каждые N сообщений.
- **Настройки** — сервер и модель, окно по умолчанию, лимит шагов, заплатки для маленькой модели, браузер, память.

## Данные

Всё в папке `data/` (вне git): `settings.json`, `projects/`, `sessions/`, `conversations/` (история — JSONL),
`skills/` (+ `.history/`), `skills-env/` (общее venv скиллов), `secrets/`, `memory/`, `wiki/`.
В папке проекта Мипо пишет служебное в `.meepo/` (логи команд, состояние скиллов, скриншоты).

## Перенос со старого Мипо

Старые данные — в `data-old/`. Один раз:

```bash
uv run python -m meepo.migrate
```

Переносятся заметки вики и память о вас (вместе с подтверждённым QA-опытом — в `solutions.md`). История чатов и
проекты не переносятся. Повторный запуск ничего не дублирует; `data-old/` не меняется.

## Скиллы

Скилл — папка `data/skills/<имя>/` с `SKILL.md` (имя, описание, entry, requires, secrets, timeout и инструкция)
и `scripts/`. Скрипт получает аргументы JSON-объектом в stdin, пишет итог в stdout и прогресс строками в stderr.
Помощник `meepo_skill` (аргументы, прогресс, запрос к модели, состояние для продолжения) доступен любому скиллу.
Стартовые: `testcase-generate`, `testcase-review`, `to-markdown`.

## Разработка

```bash
uv run pytest
```

Тесты идут на фейковой модели, без LM Studio. Правила проекта — в `CLAUDE.md`, задание и решения — в `PLAN.md`.

Обычный чат можно создать в группе «Чаты» в боковой панели. Инструменты работают в отдельной папке `data/chat-workspaces/<id сессии>/`; файловый браузер доступен в чатах проектов. Рабочая папка сохраняется после удаления чата.
