# Мипо — правила проекта

Задание и решения — в `PLAN.md`. Старый код — в `TRASH/`: только источник кусков, не импортировать.

- Один агент, простой цикл. Новые возможности — скиллами, не кодом ядра.
- Встроенный инструмент добавляется, только если его нельзя сделать скиллом (нужна живая сессия или доступ к ядру).
- Никаких новых зависимостей, SQLite, MCP, графов, субагентов без явного решения пользователя.
- Заплатка для модели — только новым файлом в `agent/guards/` с описанием и переключателем.
- Всё, что меняет файлы, систему или браузер, — через карточку подтверждения.
- Тексты, комментарии и промпты — по-русски.
- Каждая папка пакета начинается с короткого `README.md`. Файл длиннее ~300 строк или функция длиннее ~60 строк — повод разделить.
- Работает на Windows и Linux: пути только через `pathlib`, ничего Linux-only.
- Тесты: `uv run pytest`, с фейковой моделью (`meepo/llm/fake.py`), без LM Studio.
