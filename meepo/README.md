# meepo

Приложение Мипо: локальный ассистент QA-инженера.

- `main.py` — запуск сервера; `app.py` — сборка FastAPI (сервисы, роуты, статика UI).
- `settings.py` — `.env` (адрес модели, порт) и `data/settings.json` (выбор из UI).
- Подпапки: `llm/` модель, `agent/` основной агент, `skills/` скиллы, `memory/` память,
  `wiki/` вики, `storage/` сессии и проекты, `api/` HTTP-роуты, `ui/` веб-интерфейс.
