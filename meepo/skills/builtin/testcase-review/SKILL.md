# Что делает
Проверяет тест-кейсы в Markdown — таблицей (строка — кейс) или разделами. Кейсы режутся на пачки, каждая пачка —
отдельный запрос к модели с чистым контекстом, поэтому объём файла не ограничен окном модели.
С документацией (docs) — сверяет кейсы с ней: что не покрыто, что выдумано. Без документации — только качество,
стиль, проверяемость ожидаемых результатов и дубли. Готовые пачки сохраняются: повторный запуск продолжает
с места остановки.

# Аргументы (JSON)
- cases — файл .md с тест-кейсами или папка с такими файлами (обязательно)
- docs — файл .md или папка документации для сверки (необязательно)
- limit — сколько файлов кейсов проверить за запуск (по умолчанию 20)

# Результат
Рядом с каждым файлом кейсов — <имя>.review.md: замечания по пачкам со ссылкой на ID кейса и вывод.
Если в таблице кейсов есть колонка «Вопросы», в неё дописываются вопросы к требованиям (прежний файл
сохраняется копией в папке состояния скилла). В stdout — список файлов замечаний и выводы.

# Примеры
{"cases": "testgen/test_cases/docs/auth.md", "docs": "docs/auth.md"}
{"cases": "cases/login.md"}
