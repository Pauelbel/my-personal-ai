# Что делает
Переводит документы в Markdown пакетом markitdown (Microsoft). Результат — рядом с документом:
docs/spec.pdf → docs/spec.md, или по пути save. Чужой файл .md с таким именем не перезаписывается —
результат тогда ляжет в docs/spec.pdf.md. Папка обрабатывается со всеми вложенными папками; документы,
у которых перевод новее самого документа, пропускаются — повторный запуск переводит только новое и
доделывает то, что не успело. Скан без текстового слоя (картинки страниц) так не перевести: нужен OCR.

# Аргументы (JSON)
- path — документ или папка проекта (обязательно)
- save — куда записать: файл .md для документа, папка для папки (необязательно; по умолчанию — рядом)

# Результат
Файлы .md; в stdout — что во что переведено и сколько символов. Большой результат читай через read_file кусками.

# Примеры
{"path": "specs/spec.pdf"}
{"path": "docs", "save": "docs-md"}
