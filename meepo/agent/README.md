# agent

Основной агент: один простой цикл хода без графов и субагентов.

- `loop.py` — цикл хода; `prompt.py` — системный промпт и список скиллов.
- `context.py` — сборка контекста и сжатие под окно модели.
- `approvals.py` — карточки подтверждения и доверие в сессии.
- `tools/` — встроенные инструменты; `guards/` — заплатки для маленькой модели.
