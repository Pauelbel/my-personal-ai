# Заплатки агента

Заплатка — Python-модуль, который проверяет состояние хода и при необходимости возвращает подсказку. Код запускает агент; импортов в самом файле заплатки для этого не требуется.

## Как работает promise

1. `registry.py` импортирует `promise` и регистрирует его в `ANSWER_GUARDS`.
2. В `agent/loop.py`, когда модель вернула текст без вызова инструмента, `_loop` сохраняет его в `state.answer` и вызывает `registry.answer_hint(state)`.
3. Реестр по порядку вызывает `check(state)` каждой включённой ответной заплатки до первой вернувшей подсказку. `promise.check` проверяет лимит, наличие предыдущего шага с инструментами, остановку хода и последнюю строку ответа.
4. Если `check` вернул `HINT`, `_nudge` увеличивает счётчик, сохраняет ответ как промежуточный, добавляет подсказку в сообщения модели и продолжает цикл. Если вернул `None`, проверка продолжается; при отсутствии других подсказок ответ становится итоговым.

Правьте `promises_action` для распознавания текста, `check` для условий запуска, `HINT` для инструкции модели и `MAX` для лимита за ход. Переключатель хранится в `data/settings.json` в `guards.promise` и доступен в настройках. Описание и код в интерфейсе читаются непосредственно из файла модуля.

## Как добавить ответную заплатку

1. Создайте здесь файл, например `example.py`, с описанием в docstring (для названия в интерфейсе начните с `Guard «название»: …`) и функцией `check(state) -> str | None`. Верните подсказку для модели при срабатывании или `None`, если она не нужна. Ограничьте число срабатываний через `state.counts.get("example", 0)`: иначе цикл может продолжаться бесконечно.
2. В `registry.py` импортируйте модуль и добавьте `"example": example` в `ANSWER_GUARDS` в нужном порядке, а также текст сообщения для `"example"` в `LOG`. Первой сработавшей заплатке отдаётся приоритет. `ALL` автоматически включает ответные заплатки для интерфейса.
3. В `settings.py` добавьте `"example": True` в `default_guards()`. Это включает её по умолчанию, добавляет переключатель и разрешает сохранять его через API; сохранённое пользователем значение имеет приоритет.
4. Добавьте проверки в `tests/test_guards.py` и запустите `uv run pytest`. После изменения Python-кода перезапустите приложение.

Доступные поля описаны в `TurnState` в `agent/loop.py`: например, `answer` — ответ модели, `rounds` — число выполненных раундов инструментов, `stopped` — остановка по лимиту, `counts` — счётчики срабатываний за ход, `guards` — переключатели. Для заплаток плана также доступна сессия через `state.session()`.

`retry` — особый случай: он вызывается отдельно из `_ask` при пустом ответе или зацикливании, до проверки ответных заплаток. Его `check` управляет повтором запроса и `state.without_tools`; добавление другого обработчика ошибок потребует изменений в `_ask`.
