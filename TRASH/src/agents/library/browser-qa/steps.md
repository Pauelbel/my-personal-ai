Проходит тест-кейсы в браузере и сохраняет протокол в reports/browser-check.md.

## Нужно от вас
- сайт — адрес тестируемого сайта
- тест-кейсы — путь к Markdown-файлу с тест-кейсами
- доступы — логины и пароли, если нужны (необязательно)

## Пройти тест-кейсы
агент: Открой {сайт}. Прочитай файл {тест-кейсы} и выполни каждый кейс и каждый шаг по порядку. Доступы: {доступы}. Для каждого шага запиши ожидаемый и фактический результат и один статус: passed, failed, blocked или error. failed ставь только при подтверждённом расхождении продукта с ожиданием; отсутствие доступа или данных — blocked. Для failed приложи точный текст со страницы и сделай скриншот. Сохрани полный протокол через write_file в reports/browser-check.md.
инструменты: браузер, файлы
шагов: 100
